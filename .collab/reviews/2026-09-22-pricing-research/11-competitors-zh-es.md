**Access date for all rows: 2026-09-22**, via WebSearch and WebFetch (plus limited read-only Browser-pane use for
JavaScript-rendered pricing pages — no login, no forms submitted, no accounts created, no cookie-consent choice

**Methodology notes (read before the table):**
- **zh price source priority**: per the brief, most zh vendor pricing/membership pages sit behind WeChat login.
  Wherever possible this file uses the **Apple App Store China storefront** (`apps.apple.com/cn/...`) "App 内购买
  项目" (In-App Purchase) list, which renders server-side in plain HTML and needed no login. This is a genuine
  price source, but it is Apple's iOS billing surface — it does not show whether the same product's Android /
  WeChat Mini-Program (小程序) surface has different prices, and it never shows WeChat Pay/Alipay as options
  (Apple IAP is billed only through the Apple ID).
- **es SERP visibility**: the WebSearch tool used here is **US-geolocated** (its own tool description states this).
  "Top results for `chat con pdf gratis` / `ia para leer pdf gratis` / `ia para investigar gratis` from es and mx"
  could not be regionally verified — what follows is a US-geolocated web search run with Spanish-language queries,
  not a confirmed Spain/Mexico SERP. This is recorded as a limitation, not papered over.
- **Baidu SERP**: attempted directly by fetching `www.baidu.com/s?wd=...`. Unlike the es case, this rendered a
  normal results page with no CAPTCHA wall (see `## Gaps` for the query that worked and what it returned). Its
  results are named in Gaps rather than added as full table rows, to stay inside the 16-row cap while keeping the
  explicitly-named products (which the brief prioritizes) in the table.
- **Two different fetch paths were used, and they carry different reliability.** WebFetch relays page content
  through a summarizing model before it reaches this file — most of its output here is quoted directly where the
  fetch returned exact sentences, but a few cells are explicitly flagged `secondary`/paraphrase where the tool
  characterized rather than quoted the source (see Gaps). The Browser-pane reads — `vip.wps.cn`, `chatdoc.com`,
  `sider.ai/pricing`, `chatgpt.com`, `popai.pro/pricing`, `ai.wps.cn` — are directly observed: page text and
  screenshots read by this session with no intermediate summarization, and are the strongest-confidence rows in
  this file.
- **DocTalk Free baseline used for the last column** (verified 2026-09-22, given by the research lead): sign-in
  required to upload; 500 credits once at signup + 300/month that never expire (Flash ≈ 5 credits/answer, Pro ≈ 15);
  3 documents; 3 open conversations/document; 50 MB / 750 pages per file; 20 Pro-model answers/month; no export.
  Anonymous visitors get 3 demo documents, 5 messages per (IP, document) per 24 h, no upload.
- Every price below is quoted in the currency the source page displayed (¥ = CNY on the China App Store; $ = USD;
  € = EUR as rendered to this session — see the es methodology note in `## Gaps` on why a Eurozone price appeared).
