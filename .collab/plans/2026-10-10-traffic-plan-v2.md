## 2. "Where does traffic come from" — synthesis rule

One channel table per ISO week since 10-06 (first full week after Release A) and one per month.

| Source | Measures | Gate / bias | Role |
|---|---|---|---|
| `product_events.metadata_json` (`ref_host`, `utm_*`, `landing_path`) on `landing_cta_clicked`, `auth_modal_opened`, `auth_provider_clicked`; live since 09-30 21:59Z | Site-side arrivals that engaged / tried to sign up, by referrer | Un-gated. First touch lives in module memory → lost on full reload → **unattributed is overcounted**; counts events, not users | **Primary** for every channel. Shares computed on attributed events only; the unattributed fraction reported beside them |
| GA4 first users by source / channel | Consenting arrivals | Consent-gated; coverage ≈ 0.1–0.3 | Direction only. Coverage ratio = GA4 first users ÷ un-gated (`cta` + `auth_opened`) per week; < 0.3 → GA4 shares carry the caveat |
| GSC clicks (Google), BWT clicks (Bing) | Engine-side clicks | Un-gated; never 1:1 with site events | Ground truth for the two search channels; shown side by side, not reconciled |
| Ahrefs Brand Radar | Which prompts / engines cite which URLs | Sampled, monthly-ish | Explains the AI channel; never counts as arrivals |
| Ahrefs / Semrush organic traffic | Modelled | Model | Context only |
| `users.created_at` weekly, activated vs not (SQL-1) | Outcome | Pre-sign-in events carry no `user_id` → no join | Outcome column at the weekly aggregate only |

Channel mapping: **Google** = `ref_host ~ google.*` ⇄ GSC clicks · **Bing** = `bing.com` ⇄ BWT · **AI assistants** = `chatgpt.com`, `perplexity.ai`, `copilot.microsoft.com`, `gemini.google.com`, `claude.ai`, or `utm_source=chatgpt.com` ⇄ GA4 "AI Assistant" ⇄ Brand Radar · **Referral** = any other host ⇄ Ahrefs referring domains · **Unattributed** = none.

**Proven** (the audit's 3-of-3, unchanged): (i) ≥ 5 attributed events/week and ≥ 20 % of attributed events for ≥ 2 consecutive weeks; (ii) an independent source agrees in direction (GA4 same source, GSC/BWT clicks, or Brand Radar citing the landing URL); (iii) for a *change*, a mechanism or timing anchor. Two of three → CORRELATED; GA4 alone → HYPOTHESIS.

**Release B read, pre-registered now:** baseline window = 09-30 21:59Z → the B ship timestamp (logged in `actions-log.md`); metric = weekly events with (`ref_host=chatgpt.com` or `utm_source=chatgpt.com`) and `landing_path` ∈ the three listicle paths. Read 11-07: ≥ 3× the baseline weekly rate, **or** Brand Radar / probe tier a/b on ≥ 2 of P-C1, C4, C6, C8 → C-9 supported; otherwise KILLED.
